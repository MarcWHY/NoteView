# NoteView 的 OBS 输出

NoteView 提供独立的本地浏览器输出。桌面窗口最小化后，电钢琴的 MIDI 接收、音符、踏板和和弦画面仍会更新；OBS 通过浏览器源读取这份画面。

## 添加浏览器源

1. 启动 NoteView，确认电钢琴已连接。在 **设置 → OBS 输出** 中保持输出开启，然后点击 **复制 OBS 地址**。此功能默认开启。
2. 打开 OBS，选择用于直播或录制的场景。在「来源」中点击 **＋ → 浏览器**，名称可以填写 `NoteView`。
3. **不要勾选「本地文件」**。填写以下参数：

   | 选项 | 值 |
   | --- | --- |
   | URL | `http://127.0.0.1:18765/` |
   | 宽度 | `1120` |
   | 高度 | `640` |
   | 使用自定义帧率 | 开启 |
   | FPS | `30` |

4. 确认后，在 OBS 预览中移动或缩放该来源，放到需要的位置。
5. 弹几个音确认画面更新，再最小化 NoteView。继续弹琴，浏览器源应持续显示新的演奏状态。

OBS 浏览器源的 URL、画布大小与自定义帧率都是其内置选项，参见 [OBS 官方浏览器源说明](https://obsproject.com/kb/browser-source)。无需安装 OBS 插件，也不需要勾选游戏采集中的「允许窗口透明」。

## 透明背景与窗口状态

- 输出背景跟随 NoteView 的背景颜色和不透明度。在 NoteView 中选择 **设置 → 全透明**，或将背景不透明度调为 **0%**，即可在 OBS 中保留透明背景和音符的半透明效果。
- 将浏览器源放在摄像头、视频或其他背景来源的上方，才能看到透明叠加效果。OBS 场景后方没有其他内容时，透明区域会露出预览的黑色底。
- 可以最小化 NoteView；不要退出程序。退出会断开 MIDI 并关闭本地输出。用 **Ctrl+Alt+N** 或双击系统托盘图标可找回桌面窗口。
- OBS 输出与桌面窗口分开绘制，最小化桌面窗口不影响输出。OBS 的来源本身仍需在当前场景中可见。
- NoteView 不产生音频。需要录制电钢琴声音时，在 OBS 中另外添加对应的音频输入。

## 连接排查

**浏览器源没有画面：**

1. 确认 NoteView 正在运行，**设置 → OBS 输出** 已开启，设置中没有输出错误提示。
2. 检查 OBS 使用的是 **浏览器** 来源，URL 完整填写为 `http://127.0.0.1:18765/`，没有勾选「本地文件」。
3. 可以在本机浏览器中打开同一地址检查输出，再在 OBS 的浏览器源属性中点击 **刷新当前页面缓存**。
4. 如果 NoteView 提示端口被占用，先关闭另一份 NoteView 或占用该端口的程序，再点击 **重试输出**。

**最小化后「窗口采集」停住或消失：**

改用上面的 **浏览器源**。OBS 的 Windows 窗口采集会检测窗口是否已最小化，并停止正常输出；换成另一种窗口采集方式也无法保证最小化后持续更新。NoteView 的独立输出不依赖被采集窗口是否可见。[OBS 窗口采集源码](https://github.com/obsproject/obs-studio/blob/31.0.0/plugins/win-capture/window-capture.c#L375-L397)

**普通「窗口采集」出现整块黑屏：**

如果只想采集保持展开的桌面窗口，在窗口采集属性中将 **采集方式** 从「自动」改为 **Windows 10 (1903或更新版本)**。NoteView 使用 WPF 透明窗口，而 OBS 的自动选择可能落到不适合这种窗口的 BitBlt 路径。Windows Graphics Capture 使用支持 alpha 的合成方式；这一设置针对展开的桌面窗口，最小化持续输出仍应使用浏览器源。[OBS 自动采集选择源码](https://github.com/obsproject/obs-studio/blob/31.0.0/plugins/win-capture/window-capture.c#L104-L155)、[WGC 透明合成源码](https://github.com/obsproject/obs-studio/blob/31.0.0/libobs-winrt/winrt-capture.cpp#L471-L515)

## 本地运行

`127.0.0.1` 是本机回环地址。这份输出只供同一台电脑上的 OBS 或浏览器读取，不需要联网，不会上传演奏数据，也不向电钢琴发送 MIDI。关闭 **设置 → OBS 输出** 或退出 NoteView 会停止服务。
