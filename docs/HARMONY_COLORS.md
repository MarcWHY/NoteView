# 和声配色

这是一套表达和声气质的视觉设计，不把冷暖、情绪或紧张感视为客观固定的乐理标签。

| 和声组 | 主色倾向 |
| --- | --- |
| 大三、六、大七及同组加音 | 暖金、杏色 |
| 小三、小七及小和弦扩展 | 冷蓝 |
| 挂留、五度、省略三音 | 青绿 |
| 属七及属和弦扩展 | 珊瑚橙 |
| 减、半减 | 紫色 |
| 增、升五 | 粉紫 |
| 降九、升九、降十三等变化色彩 | 玫红 |

不同根音在所属色系中有固定的色相差异，没有随机选色。五线谱音符、键盘亮键和和弦名称使用同一颜色。轻重演奏不改变颜色，只影响亮度。

首次和声确认约需 80 毫秒，后续切换约需稳定 180 毫秒，再用 140 毫秒过渡。相同根音与和声组保留配色，包括转位与常见加音。和弦名称与配色共用基底判断：支撑五音仍按住或明显延留时，孤立的新音优先看作经过音。重新奏出至少三个音级的新配音，或原支撑音衰弱后，可建立新基底。单独加一个新低音也不会立即覆盖旧基底。

优先参考至少三个不同音级构成的、可识别的实按和弦，再参考包含踏板音的整体。未识别时延续上一组染色；无演奏持续约 1.5 秒后回到中性的蓝灰。没有历史和声的单音也使用中性色。和弦文字仍仅在识别成功时显示。

击键亮度由 MIDI velocity 映射，之后沿用快速起始衰减和缓慢尾段，实按最低保留该次击键亮度的 14%，踏板音最终消失。OBS 使用桌面的颜色快照，不另行识别或计时。

例：Dm 的 A 仍明显延留时加入 B♭，名称继续显示 Dm、配色不变；重新弹出 B♭–D–F 后允许切换。

界面统一使用 ♭、♯，大七／大九等用 △7／△9，减和弦用 °，半减用 ø，增和弦用 +。例如 B♭△7、F♯°7、Cø7、Cm(△7)。
