# 和声配色

这是一套表达和声气质的视觉设计，不把冷暖、情绪或紧张感视为客观固定的乐理标签。

| 和声组 | 主色倾向 |
| --- | --- |
| 大三、六、大七及同组加音 | 暖金、杏色 |
| 小三、小七及小和弦扩展 | 冷蓝 |
| 挂留、五度、省略三音 | 青绿 |
| 属七及属和弦扩展 | 珊瑚橙 |
| 减、半减 | 紫色 |
| 增、升五 | 粉紫 |
| 降九、升九、降十三等变化色彩 | 玫红 |

不同根音在所属色系中有固定的色相差异，没有随机选色。这些颜色是和声的基底；具体的音符还会根据它与基底、前一和声的关系染色。五线谱和键盘上的同一个音使用相同颜色。力度只控制亮度，不控制色相。

首次和声确认约需 80 毫秒，后续切换约需稳定 180 毫秒。主色随后用约 0.65–1.2 秒过渡；共同音越多，过渡越舒缓。前一和声的余色最多保留约 3.2 秒，体现在和弦名称的渐变和背景的另一片柔光中。连续转和弦从当时已经混合的颜色继续，不会跳回某个固定起点。

共同音延续底色，新进入的和弦音在过渡时带出强调色。增加张力时偏玫红，释放张力时偏琥珀；同样落到 C 大和弦，从属和弦解决而来和从较远和弦转来会经历不同的色彩过程。转位不会重新触发过渡，同组加音保留主色。

基底外的音单独染色：二度、六度偏青，挂留音偏绿，半音和三全音偏玫红，降六度偏暖橙。已识别的扩展音与主色轻度混合，保持比基底外音更统一的观感。新基底之外的旧踏板余音继续保有原色，并按原来的亮度曲线淡出；属于新和弦的共同音随基底柔和过渡。

和弦名称与配色共用基底判断：支撑五音仍按住或明显延留时，孤立的新音优先看作经过音。重新奏出至少三个音级的新配音，或原支撑音衰弱后，可建立新基底。配色变化本身不会强迫和弦重新命名。

优先参考至少三个不同音级构成的、可识别的实按和弦，再参考包含踏板音的整体。未识别时保留上一基底，以音符局部色彩表达变化；无演奏持续约 1.5 秒后开始回到中性的蓝灰，背景柔光也会淡出。没有历史和声的单音使用中性色。和弦文字仍仅在识别成功时显示。

背景柔光与基底、变化音及历史余色同步，围绕五线谱、琴键和和弦区域散开。设置中的“和声氛围”默认很淡，可以单独调整或降为 0。背景不透明度为 0 时仍可保留这些局部柔光；需要完全干净的透明叠加时，把背景不透明度和氛围都设为 0。

击键亮度由 MIDI velocity 映射。实按音的初始高亮按 0.16 秒时间常数回落，尾段时间常数为 4.8 秒，最低保留该次击键亮度的 14%。松键后从当前亮度连续过渡到踏板延留：两个阶段都会加速，并叠加 1.8 秒的整体淡出，最终消失。OBS 使用桌面的颜色快照，不另行识别或计时。

例：Dm 的 A 仍明显延留时加入 B♭，名称继续显示 Dm，D–F–A 保留冷蓝，B♭ 带出暖橙，背景出现少量对应色彩；重新弹出 B♭–D–F 后允许转到 B♭ 主色，并短暂保留 Dm 的蓝色余韵。

界面统一使用 ♭、♯，大七／大九等用 △7／△9，减和弦用 °，半减用 ø，增和弦用 +。例如 B♭△7、F♯°7、Cø7、Cm(△7)。
